# Spendly backend

Express and MongoDB API for [Spendly](https://github.com/mp8651188-bit/Spendly), maintained by [@mp8651188-bit](https://github.com/mp8651188-bit).

Create `.env` using the configuration in the [main README](../README.md), then run:

```bash
npm install
node server.js
```

The local API runs at http://localhost:8000. Configure MongoDB, SMTP, and Google OAuth for the corresponding services.

See [email setup](EMAIL_SETUP.md) for mail configuration and the [main README](../README.md) for screenshots and original project credits.

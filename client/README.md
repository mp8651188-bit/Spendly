# Spendly frontend

React frontend for [Spendly](https://github.com/mp8651188-bit/Spendly), maintained by [@mp8651188-bit](https://github.com/mp8651188-bit).

```bash
npm install
npm start
```

Open http://localhost:3000. The backend is expected at http://localhost:8000.

Use `npm run build` to create a production build.

See the [main README](../README.md) for features, setup, screenshots, contact details, and original project credits.
